02 / THE FIRST WORKSPACE

Built for the
curious mind.

Schwab Lab includes Flight Lab for experimental trajectory review and Design Archive for post-flight data review and OpenRocket design inspection. It brings visual intuition together with the mathematics of vectors and time-series analysis.

Start with an illustrative example, inspect an OpenRocket file, or import measured data. Save projects in your browser and export portable JSON backups; nothing is uploaded to a server.
